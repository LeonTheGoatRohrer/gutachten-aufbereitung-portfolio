# Pruefprompt: Dateiklassifikation

Pruefe, ob die Dateirollen plausibel sind.

Erfolgskriterien:

- Jede Datei hat eine Kategorie.
- Excel-Dateien mit Chlorid/Analyse/TIQU/BDB werden als Labor-Kandidaten gezeigt.
- Word-Dateien mit Gutachten/Vorlage werden als Vorlagen-Kandidaten gezeigt.
- PDF-Dateien werden als Anlagen gefuehrt.
- Benutzerbestaetigung bleibt erforderlich.

Warnung, wenn mehrere Labor- oder Word-Kandidaten existieren.
