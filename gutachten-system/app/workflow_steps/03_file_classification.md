# 03 Dateien erkennen und klassifizieren

## Ziel

Das System schlaegt Rollen fuer importierte Dateien vor.

## Kategorien

- Gutachtenvorlage
- Laborwerte
- Vor-Ort-Werte
- Bilder
- Anlagen
- Anlagenverzeichnis
- Sonstiges

## Vorgehen

1. Dateiendung auswerten.
2. Dateinamen nach typischen Begriffen pruefen.
3. Kandidatenlisten fuer Word-Vorlage und Labor-Excel erzeugen.
4. Benutzer muss Labor-Datei und Vorlage bestaetigen.

## Ergebnis

`file_inventory` enthaelt alle Dateien mit Kategorie und Pfad.
