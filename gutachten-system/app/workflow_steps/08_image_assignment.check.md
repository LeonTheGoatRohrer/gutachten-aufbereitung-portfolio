# Pruefprompt: Bildzuordnung

Pruefe die Zuordnung von Bildern zu Proben.

Erfolgskriterien:

- Jede Zuordnung wurde bestaetigt oder bewusst offen gelassen.
- Bildtypen sind gesetzt.
- Doppelte Zuordnungen sind sichtbar.
- Unzugeordnete Bilder werden gemeldet.
- Keine blinde automatische Endzuordnung.

Fehler, wenn Bilder ohne Kontrolle als sicher zugeordnet wurden.
