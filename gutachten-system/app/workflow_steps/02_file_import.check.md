# Pruefprompt: Dateien importieren

Pruefe den Dateiimport.

Erfolgskriterien:

- Importquelle existierte und wurde nicht als Zielordner verwendet.
- Dateien wurden nach `00_original/` kopiert.
- Keine Originaldatei wurde ueberschrieben.
- Anzahl kopierter Dateien ist protokolliert.
- Dateipfade sind relativ zum Projekt nachvollziehbar.

Fehler, wenn Quelldaten geloescht, verschoben oder ueberschrieben wurden.
