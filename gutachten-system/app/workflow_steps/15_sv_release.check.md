# Pruefprompt: SV-Freigabe

Pruefe die fachliche Freigabe.

Erfolgskriterien:

- Kritische Bewertungen wurden bewusst bestaetigt.
- Kommentare/Korrekturen sind nachvollziehbar.
- Kein finaler Status ohne SV-Aktion.
- Entwurf und Finaldatei sind unterscheidbar.

Fehler, wenn das System selbst eine fachliche Endfreigabe gesetzt hat.
