# Pruefprompt: Textbausteine

Pruefe die erzeugten Texte.

Erfolgskriterien:

- Zahlen stimmen mit Masterliste ueberein.
- Keine erfundenen Projektinformationen.
- Fachliche Endentscheidungen sind als Vorschlag markiert.
- Texte enthalten keine widerspruechlichen Probenzahlen.

Fehler, wenn Textzahlen von Tabellenzahlen abweichen.
