# Pruefprompt: Projekt anlegen

Pruefe, ob das Projekt korrekt initialisiert wurde.

Erfolgskriterien:

- Projektordner existiert.
- Alle Standard-Unterordner existieren.
- `project_state.json` ist gueltiges JSON.
- Stammdaten sind unveraendert aus der Eingabe uebernommen.
- Es gibt einen Logeintrag zur Projekterstellung.

Fehler, wenn Ordner fehlen oder die Statusdatei nicht lesbar ist.
