# Pruefprompt: Karbonatisierung

Pruefe die Karbonatisierungsbewertung.

Erfolgskriterien:

- Jeder Wert hat eine Quelle oder SV-Bestaetigung.
- Unsichere Schaetzungen sind markiert.
- `an Bewehrung` wird als kritisch behandelt.
- Fehlende Werte bleiben sichtbar offen.
- KI-Texte sind nur Vorschlaege.

Fehler, wenn ein automatischer Vorschlag als SV-Freigabe gespeichert wurde.
